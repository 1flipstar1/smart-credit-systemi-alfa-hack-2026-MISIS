# Официальная Core Components

В проект полностью устанавливается `@alfalab/core-components@50.37.0` с зависимыми пакетами, темами и токенами. React 18.3.1. Установка: `npm ci`.

- Официальная документация: https://core-ds.github.io/core-components/master/?path=/docs/intro--docs
- Исходники: https://github.com/core-ds/core-components
- `COMPONENTS.md` — полный каталог установленного метапакета со ссылками на API.
- `api/` — копии всех деклараций TypeScript зависимых Core Components пакетов, включая общие и наследуемые типы; это точный справочник доступных параметров, типов и комментариев.
- `storybook-index.json` — снимок полного индекса опубликованного Storybook, а не гарантия совпадения master с установленным релизом.
- `manifest.json` — версии, пути пакетов и источники типов.

Не пытаться запомнить все параметры. Перед изменением компонента читать его API и прослеживать ссылки на общие типы в node_modules. Для значения по умолчанию, не указанного в декларации, смотреть установленную реализацию. Для поведения и примеров использовать официальный Storybook.

`npm run ds:catalog` воспроизводимо обновляет локальный справочник из установленных пакетов без сети. `npm run build` собирает настоящие компоненты в автономные HTML, которые можно открывать через file://. `npm run dev` запускает локальный просмотр. `npm run verify` проверяет пять сценариев, галерею, мобильные размеры и ошибки браузера.

Используем официальную тему `site.css` и типографику библиотеки. Акцентный CTA — `Button view="accent"`; `primary` в актуальном API имеет другой смысл. Размеры Button и Tag проверяются по установленным типам (например, Button 40/56, Tag 32). Цвет прогресса — `ProgressBar view="accent"`. Styrene UI 400/500/700 подключён из `src/fonts.css` и встраивается в HTML; основной текст использует официальный системный стек. Правила и источники — [../typography.md](../typography.md). Прежнее исследование по картинкам сохранено как исторический материал; оно не определяет API и токены.

Справочник копирует декларации официальных npm-пакетов с оригинальными комментариями; авторство — разработчики Alfa Core Components, лицензия пакетов MIT. Версии каждого пакета перечислены в manifest.json. Это снимок API установленной версии.
