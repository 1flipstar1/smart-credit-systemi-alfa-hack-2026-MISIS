# Информационный блок Core Components

Откройте alfa-credit-concepts.html напрямую в браузере. В нём остался информационный блок со ссылкой на официальную документацию. Пять концепций и их превью удалены.

Исходники — ../../src. Сборка из корня: npm run build. Проверка и обновление превью: npm run verify. Результаты — verification-core-components.json, desktop-превью — gallery-core-components.png, мобильное — information-mobile.png.

Исторические исследования и референсы сохранены. Не запускайте build_study.py и verify_study.py: они относятся к удалённым наброскам. Источник API — ../../docs/core-components и установленный пакет.
