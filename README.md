# Альфа-Бизнес · умный кредитный кабинет

Единый сайт с каталогом бизнес-кредитов, подбором продукта, заявкой, документами и рабочим местом банка. Все экраны открываются в одной странице; переходы записываются в историю браузера. «Назад» и «Вперёд» сохраняют введённые параметры, выбранный продукт и прокрутку. Перезагрузка открывает текущий экран.

Главная страница: `output/prototype/alfa-credit-cabinet.html` — можно открыть напрямую. Для запуска по HTTP:

```sh
npm ci
npm run check
npm run build
npm run verify
npm run dev
```

Локальный просмотр: http://127.0.0.1:4173. Клиент и кабинет банка используют один адрес с маршрутами `#home`, `#params`, `#company`, `#docs`, `#review`, `#status`, `#sign`, `#done`, `#adm`, `#adm-card`, `#adm-analytics`. Старые ссылки `#apply`, `#admin`, `#bank`, `#analytics` продолжают работать. Проверка использует установленный Chrome или Chromium из Playwright.

Исходник сайта — `src/prototype.html`. Блок оформления по банковскому референсу, заявка сразу под ним, краткие условия и заключительная чёрная карточка подбора — настоящие React-компоненты в `src/credit-sections.tsx`, композиция — `src/credit-sections.css`. Заявка использует `Input`, `Button` и `Typography` с проверкой ИНН и телефона. Сборка встраивает компоненты, тему `site.css`, шрифты, иллюстрации и резервные данные каталога в один HTML. Полный раскрывающийся список предложений с главной убран; каталог из 33 предложений сохранён в БД и API. Номера шагов — декоративная инфографика с пунктирными кольцами; все тексты и интерактивные элементы новых блоков используют Core Components. Отдельный информационный пример дизайн-системы (`src/app.tsx`, `src/layout.css`) доступен по `/alfa-credit-concepts.html`.

Каталог хранится в таблицах `credit_products` и `credit_product_categories`. Источник начальных данных — `credit_cabinet_backend/app/db/credit_catalog.json`: 33 предложения в пяти группах, опубликованные условия и параметры выбора. При запуске API `init_db()` добавляет недостающие поля старой БД и отсутствующие записи каталога, сохраняя существующие заявки и изменения продуктов. API: `GET /api/products`, фильтр `?category=line`, `GET /api/products/summary`, `GET /api/products/{code}`. Сводка показывает минимальную опубликованную ставку, максимальную сумму и срок по группе; они могут относиться к разным продуктам. Неопубликованные условия остаются пустыми и отображаются как индивидуальные. Это справочный снимок предложений, а расчёты прототипа предварительные.

Без API сайт использует встроенный при сборке каталог и локальную демонстрацию. Чтобы сохранять заявки и каталог в БД, запустите API из `credit_cabinet_backend` (после установки `requirements.txt`): `python -m uvicorn app.main:app --port 8000`. В отдельном терминале оттуда же запустите `python -m app.workers.document_worker`. По умолчанию используется SQLite `credit_cabinet.db`; `DATABASE_URL` позволяет подключить другую БД. Docker-конфигурация API, PostgreSQL и worker — `credit_cabinet_backend/docker-compose.yml`. Адрес API для сайта можно задать параметром `?api=http://localhost:8000` перед hash-маршрутом.

`npm run verify` проверяет типографику всего действующего интерфейса по стилям установленной библиотеки: экраны клиента и банка, поля, подписи, плейсхолдеры, ошибки, модальные окна, раскрытые блоки, уведомления и галерею на ширинах 1440, 720 и 390. Также проверяются положение и валидация заявки, последняя карточка подбора, автономные шрифты, данные каталога, «Назад»/«Вперёд», быстрые переходы, сохранение формы, прокрутка и перезагрузка. Превью блоков — `output/prototype/how-to-*.png`, `credit-lead-*.png`, `credit-kinds-*.png`, полный сайт — `typography-*.png`. `npm run e2e` проверяет путь клиент → банк → клиент через запущенные API и worker. Тесты API запускайте с отдельной тестовой БД: `DATABASE_URL=sqlite:////tmp/alfa-credit-tests.db python -m pytest tests/test_api.py -q` из `credit_cabinet_backend`.

Правила дизайн-системы — AGENTS.md. Каталог API — docs/core-components/COMPONENTS.md, параметры — docs/core-components/api. npm run ds:catalog обновляет справочник.

Исторические исследования и исходные референсы сохранены. Архивный build_study.py запускать не следует.

Кредитный прототип: `output/prototype/alfa-credit-cabinet.html`. Его исходник — `src/prototype.html`; он также генерируется через `npm run build`. Правила типографики, источники шрифтов и браузерные проверки описаны в [docs/typography.md](docs/typography.md).

Иллюстрации кабинета перегенерированы встроенным image_gen по промоматериалам и интерфейсам из `Библиотека ui/`. Рабочие WebP и карта соответствий — `src/assets/illustrations/`; исходные PNG с прозрачностью и точные промпты — `output/illustrations/originals/` и `output/illustrations/generation.json`. Для повторной конвертации и обновления галереи: `node scripts/prepare-credit-assets.mjs`, затем `npm run build` и `npm run verify`. Галерея — `output/illustrations/index.html`.
